# Bundled fonts

Downloaded 2026-10-04 from the official Google Fonts repository. Fonts retain their original glyphs, names and variable axes; only the container was converted from TTF to WOFF2 with fontTools 4.66.1. Each family includes its SIL Open Font License.

Bundling removes build-time Google Fonts requests that intermittently failed in Turbopack on GitHub Actions. No runtime CDN request is needed.
